# Ipple Music

一款用 SwiftUI 编写的 macOS QQ 音乐播放器。用手机 QQ 扫码后，可以在 Mac 上打开自己的歌单，边听边看逐字歌词，也可以收起主窗口，在菜单栏查看当前歌词、切歌或收藏。

**本项目仅供学习与技术交流**，适合用来了解 SwiftUI 界面、AVPlayer 播放和本地会话管理。请使用本人有权使用的账号，并遵守 QQ 音乐的平台规则和内容授权范围。

## 🎧 可以做什么

| 在哪里 | 可以做什么 |
| --- | --- |
| 发现 | 搜索歌曲、查看排行榜，播放「猜你喜欢」和每日推荐。 |
| 收藏 | 浏览个人歌单和喜欢的歌曲。点击心形按钮，收藏或取消收藏会同步到当前 QQ 音乐账号。 |
| 播放详情 | 查看评论、切换可用音质、点击歌词跳到对应时间。有逐字时间轴时歌词随播放填色，有译文时在原文下方显示。 |
| 菜单栏 | 查看当前歌词，悬停后可播放、暂停、切歌或收藏。 |
| 我的 | 调整菜单栏宽度，查看封面、歌词和音频的缓存用量，设置共享容量上限或一键清空。 |

## 快速开始

**构建需要 Xcode 26 或更高版本，应用最低支持 macOS 15。** 在仓库根目录运行以下命令即可打开应用。

```sh
make mac-run
```

首次构建需要联网。脚本会下载并校验便携版 Node 和固定版本的 [Rain120/qq-music-api](https://github.com/Rain120/qq-music-api)，安装锁定的 npm 依赖，再将运行时放入应用包。后续构建会复用本地缓存，无需另行部署后端。

也可以用 Xcode 打开根目录的 `IppleMusicMac.xcodeproj`，选择 `IppleMusicMac` 并按 `⌘R`。应用打开后，用手机 QQ 扫描登录页的二维码，在手机上核对账号与授权信息后确认。下次启动时，应用会尝试恢复登录。

## 🔒 隐私与安全

**项目维护者不会通过本应用收集你的个人信息，也没有用于存储用户数据的项目服务器。** 播放器自身保存的数据均位于你的 Mac。应用没有接入使用统计、广告追踪或崩溃上报服务。

| 数据去向 | 具体内容 |
| --- | --- |
| 本机钥匙串 | 保存 QQ 账号标识、昵称、头像地址和登录凭据。该钥匙串项已关闭同步。 |
| 本机磁盘 | 保存设置、资料库、听歌历史、播放队列、进度和媒体缓存。资料库和媒体缓存按账号隔离。 |
| QQ 音乐及其资源服务器 | 登录时接收授权信息，搜索时接收关键词，播放时接收歌曲请求，收藏时将歌曲加入或移出该账号的「我喜欢」。加载头像、封面或音频时，资源服务器也能看到请求的 IP 地址。相应服务决定如何处理这些请求及是否留存相关数据。 |

在「我的」中，**退出当前账户**会清除本机登录凭据，保留资料库和缓存。**退出并删除此账号的本机数据**还会清除该账号的本机资料库、听歌历史、播放队列和媒体缓存。已同步到 QQ 音乐的收藏可在该账号中单独管理。

> **扫码安全提示**　请使用可信来源的构建。登录二维码、授权回调链接和会话 Cookie 都应保密，提交问题报告或截图前请遮盖这些信息。

## 开发与测试

以下命令均在仓库根目录运行。自动化测试使用独立的测试数据，无需登录个人 QQ 账号。

| 命令 | 用途 |
| --- | --- |
| `make mac-build` | 构建应用，产物位于 `.local/player-build/Build/Products/Debug/Ipple Music.app`。 |
| `make mac-test` 或 `swift test` | 运行 Swift 测试，覆盖账号会话、资料库、歌词与媒体缓存等。 |
| `make qq-test` | 使用项目准备的 Node 运行 QQ 音乐适配层测试。 |

从 [Sources/IppleMusicMac](Sources/IppleMusicMac) 可以找到 SwiftUI 界面、AVPlayer 播放器和菜单栏控制器。[Sources/MusicCore](Sources/MusicCore) 包含资料库、歌词时间轴和缓存逻辑，对应测试在 [Tests/MusicCoreTests](Tests/MusicCoreTests)。QQ 音乐适配代码及上游补丁在 [QQMusicRuntime](QQMusicRuntime)。

开发构建的本机用户数据位于 `.local/public-player/`。登录背景使用项目自制的几何图案，可运行 `python3 scripts/generate-login-covers.py` 重新生成。
